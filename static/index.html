利用の記録（このアプリで使った分）

      

    

  


  
  

    
初期設定

    
Azure で作った「Speech（音声）リソース」の情報を入力します。手順は 「はじめての方へ」 にあります。


    

      
1. APIキー（合言葉のようなもの）

      
Azure ポータル → 作成したリソース → 「キーとエンドポイント」の キー1 をコピーして貼り付けます。

      

      
      

      
2. エンドポイント（接続先の住所）

      
同じ画面の「エンドポイント」をコピーして貼り付けます。例：https://あなたのリソース名.cognitiveservices.azure.com/

      

      
3. リージョン（データセンターの場所）

      
リソースを作るときに選んだ場所です。エンドポイントを入力した場合は参考情報になります。
        MAI-Transcribe-2 は日本のリージョンでは使えません。日本から一番近いのは「東南アジア（シンガポール）」です。

      

      

        
        
        
      

      
「接続テスト」は1秒の無音を送って確認します。料金は約0.003円です。

  • 文字起こしそのものは Microsoft のクラウド（Azure）で行います。このアプリは「録音を送って、結果を受け取り、見やすく整える」窓口です。
    • 
        
  • API（エーピーアイ）とは、アプリが Azure の機能を呼び出すための「窓口」のことです。
    • 
        
  • APIキーとは、その窓口を使うための「合言葉（鍵）」です。この鍵で「誰が使ったか」が判断され、その人に料金が請求されます。
    • 
      

    


    

      
⚠️ APIキーの取り扱いで大切なこと

      
    
        
  • APIキーは他人に教えないでください。メール・チャット・共有フォルダに貼らないでください。知られると、あなたの費用で勝手に使われるおそれがあります。
    • 
        
  • このアプリは APIキーを このパソコンの中（config.json）だけに保存し、外部には Microsoft 以外へ送りません。
    • 
        
  • アプリのフォルダごと人に渡すときは、config.json を削除してから渡してください。
    • 
        
  • もしキーが漏れたかもしれないと思ったら、Azure ポータルの「キーとエンドポイント」で 「キー1を再生成」 を押すと古いキーは使えなくなります。新しいキーをこのアプリに設定し直してください。
    • 
      

    


    

      
準備の手順

      
    
        
  1. 
          
    Microsoft Azure のアカウントを作る
    
          
    Azure の無料アカウント作成ページ から登録します。Microsoft アカウント（Outlook などのメールアドレス）、電話番号、クレジットカードが必要です。
    
          
    会社や学校で Azure を使っている場合は、勝手に作らず情報システム担当の方に相談してください。既存の契約（サブスクリプション）を使えることがあります。
    
        
    2. 
        
  2. 
          
    Azure ポータルにサインインする
    
          
    https://portal.azure.com/ を開いてサインインします。
    
        
    3. 
        
  3. 
          
    「Speech（音声）」のリソースを作る
    
          
    上部の検索欄に「Foundry」または「Speech」と入力し、Microsoft Foundry のリソース（または Speech サービス）の「作成」を押します。
            直接作成画面を開く
    
          
    
            
              
    サブスクリプション自分の契約を選ぶ
    
              
    リソースグループ「新規作成」で、例：minutes-app（入れ物の名前。後で丸ごと削除しやすくなります）
    
              
    リージョンSoutheast Asia（東南アジア）がおすすめ。
    Japan East / Japan West は MAI-Transcribe 非対応なので選ばないでください。
    
              
    名前半角英数字で自由に。例：minutes-yamada
    
              
    価格レベルStandard S0（無料の F0 では MAI-Transcribe が使えません）
    
                
          
    
          
    「確認と作成」→「作成」を押し、1〜2分待ちます。
    
        
    4. 
        
  4. 
          
    APIキーとエンドポイントをコピーする
    
          
    作成が終わったら「リソースに移動」→ 左メニューの「キーとエンドポイント」を開きます。キー1 と エンドポイント をコピーします。
    
        
    5. 
        
  5. 
          
    このアプリに設定する
    
          
    「④ 初期設定」 に貼り付けて「保存する」→「接続テスト」を押します。「接続できました」と出れば完了です。
    
        
    6. 
        
  6. 
          
    試しに短い録音で文字起こしする
    
          
    スマートフォンで 1 分ほど録音したファイルで試すと安心です（料金は 1 円未満）。
    
        
    7. 
        
  7. 
          
    （おすすめ）予算アラートを設定する
    
          
    Azure ポータルの検索欄で「コストの管理と請求」→「予算」→「追加」で、例えば月 1,000 円を超えたらメールが届くように設定できます。
            ※ アラートは通知だけで、自動で止まるわけではありません。
    
        
    8. 
      

    


    

      
知っておいてほしいこと

      
    
        
  • 録音データの行き先：音声は Microsoft の Azure（選んだリージョン。例：シンガポール）に送られて処理されます。日本国外で処理される点に注意し、社外秘・個人情報を含む会議では、所属組織のルールを確認してください。
    • 
        
  • 録音ファイルの扱い：このアプリは文字起こしが終わると、パソコン内に一時保存した音声を自動で削除します。元の録音ファイルはそのまま残ります。
    • 
        
  • プレビュー版：MAI-Transcribe-2 は現在「プレビュー（試験提供）」です。仕様や料金が変わる可能性があり、品質保証（SLA）はありません。
    • 
        
  • 上限：1ファイルあたり 500MB 未満・5時間未満まで。話者分離をオンにした場合は、より短い録音までしか処理できません。
    • 
        
  • 精度：AI による文字起こしには誤りが含まれます。正式な議事録にする前に、必ず人の目で確認・修正してください。
    • 
        
  • 録音の同意：会議を録音・文字起こしする際は、参加者の了承を得てください。
