# 料金とAPIキーのしくみ（IT に詳しくない方向け）

## 1. 登場人物

| 名前 | たとえると | 役割 |
|---|---|---|
| **MAI-Transcribe-2** | 腕のいい速記者 | Microsoft AI が作った文字起こしAI |
| **Microsoft Azure（アジュール）** | 速記者が所属する会社 | MAI-Transcribe-2 を貸し出しているクラウドサービス |
| **リソース** | 会社との契約窓口 | Azure 上に作る「あなた専用の利用枠」。料金はリソースごとに集計 |
| **API（エーピーアイ）** | 受付窓口 | アプリが Azure に仕事を頼むための入口 |
| **APIキー** | 契約者の合言葉 | 「誰の依頼か」を示す鍵。**この鍵の持ち主に料金が請求される** |
| **エンドポイント** | 受付窓口の住所 | `https://○○.cognitiveservices.azure.com/` のようなURL |
| **リージョン** | 速記者がいる支社の場所 | データを処理するデータセンターの地域 |
| **このアプリ** | あなたの秘書 | 録音を窓口に持って行き、結果を受け取って清書する |

```
 録音ファイル ─→ このアプリ ─(APIキーを見せる)─→ Azure (MAI-Transcribe-2) ─→ 文字起こし結果 ─→ 議事録
  (あなたのPC)      (あなたのPC)                    (例: シンガポール)                      (あなたのPCに保存)
```

## 2. 料金のしくみ

### 基本
- **従量課金（使った分だけ）**：月額の基本料金はありません。使わない月は 0 円です。
- **録音の長さで決まる**：1時間の録音なら1時間分。ファイルサイズや文字数、話者分離の有無では変わりません。
- **請求元は Microsoft**：Azure に登録したクレジットカードに毎月請求されます（米ドル建て価格を円で請求）。

### 単価（2026年10月時点）

| モデル | 1時間あたり | 備考 |
|---|---|---|
| **MAI-Transcribe-2**（このアプリが使用） | **0.10 ドル（約15円）** | **2026年12月31日までの期間限定プレビュー価格** |
| MAI-Transcribe-2-Streaming（リアルタイム用・本アプリ未使用） | 0.54 ドル | 参考 |

> ⚠️ 2027年1月以降の価格はまだ発表されていません。値上がりする可能性があります。
> 必ず [Azure Speech の料金ページ](https://azure.microsoft.com/ja-jp/pricing/details/speech/) で確認し、
> アプリの「④ 初期設定 → 料金・予算の設定」の単価を更新してください（アプリの料金表示はこの単価で計算します）。

### 目安（1ドル＝150円の場合）

| 使い方 | 料金の目安 |
|---|---|
| 30分の会議 1回 | 約 8 円 |
| 1時間の会議 1回 | 約 15 円 |
| 1時間の会議 × 月20回 | 約 300 円 |
| 「接続テスト」1回 | 約 0.003 円 |

### 注意点
- **無料プラン（F0）では MAI-Transcribe は使えません。** 価格レベルは **Standard (S0)** を選びます。
  S0 でも使わなければ料金はかかりません。
- Azure を新しく始めた人向けの無料クレジットがある場合、その範囲内なら実質無料になることがあります
  （条件は Azure の公式ページで確認してください）。
- このアプリの「③ 料金と利用状況」は**このアプリで使った分の目安**です。
  **正確な請求額は Azure ポータル →「コストの管理と請求」** で確認してください（反映まで1日ほどかかります）。

## 3. 使いすぎを防ぐには

1. **アプリの月予算**：「④ 初期設定」で月の予算（円）を決めると、「③ 料金と利用状況」で残りがわかります。
2. **Azure の予算アラート**：Azure ポータル →「コストの管理と請求」→「予算」→「追加」。
   金額を超えるとメールで知らせてくれます（※通知のみで、自動停止はしません）。
3. **やめるときはリソースを削除**：Azure ポータルで作成したリソースグループ（例：`minutes-app`）を削除すると、
   APIキーも無効になり、それ以降の料金は一切かかりません。

## 4. APIキーの安全な扱い方

| やること | やってはいけないこと |
|---|---|
| このアプリの「初期設定」にだけ貼り付ける | メール・チャット・共有フォルダ・資料に貼る |
| 人にアプリを渡すときは `config.json` を削除 | APIキーが入ったままのフォルダを配る |
| 漏れたかもと思ったら「キーを再生成」 | 気づいてもそのまま使い続ける |

- キーは2つ（キー1・キー2）あり、どちらでも使えます。
  **キーを再生成すると古いキーは即座に使えなくなります**。新しいキーをアプリに設定し直してください。
- このアプリはキーを `config.json` に保存し、Microsoft の Azure 以外には送信しません。
  画面にはキーの一部（先頭4文字と末尾4文字）しか表示しません。

## 5. データの行き先

- 音声は **選んだリージョンの Azure データセンター**（おすすめ設定ではシンガポール）に送られて処理されます。
  2026年9月時点で MAI-Transcribe は **日本のリージョンでは提供されていません**。
- 処理に使える地域：Southeast Asia（東南アジア）、Central India、East US、West US、West US 2、North Europe
- 機密情報や個人情報を含む会議を扱う場合は、所属組織のルール（クラウド利用・国外データ移転）を確認してください。

## 6. 上限

| 項目 | 上限 |
|---|---|
| ファイルサイズ | 500MB 未満 |
| 録音の長さ | 5時間未満（話者分離オンの場合はより短い） |
| 回数 | 1分間に600回まで（通常は気にする必要なし） |

※ このアプリは送信前に音声を「16kHz・モノラル」に変換するため、多くの場合ファイルは小さくなります。
